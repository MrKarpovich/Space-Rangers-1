# SR1 Trainer — Космические Рейнджеры 1

Трейнер предметов для классической игры **«Космические Рейнджеры» (2002)**.  
Поиск предмета по цене (как в Cheat Engine) и правка характеристик прямо в памяти процесса.

> Работает с оригинальным `Rangers.exe`. Не требует внешних DLL-инжектов.

## Важно — прочитай перед запуском

| Правило | Зачем |
|--------|--------|
| Игра → **режим совместимости Windows 98** + **от имени администратора** | Стабильный DirectDraw, меньше крашей |
| Трейнер → **от имени администратора** | Доступ к памяти процесса |
| Править параметры **только когда предмет в руке** и вы на **рабочем столе** (Alt+Tab из игры) | Иначе UI/логика игры могут перезаписать значения или вылететь |
| После записи **переложите предмет** (трюм ↔ слот / снимите с руки и возьмите снова) | Чтобы интерфейс игры подтянул новые цифры |
| **Уровень только 1…8** | `9` и выше → краш |
| **Раса только 0…5** | `6+` → краш / «нет расы» |
| **Type оружия только 33…47** | Вне диапазона → краш |

## Быстрый старт

1. Запустите `Rangers.exe` (Win98 + Админ).
2. Запустите `SR1_Trainer.py` или `SR1_Trainer.exe` **от Админа**.
3. В трейнере: **«Подключить к Rangers.exe»**.
4. Выберите **тип предмета**, введите его **цену** (когда он в руке).
5. Поиск:
   - предмет **в руке** → кнопка **«Предмет СЕЙЧАС В РУКЕ — искать»**;
   - убрали с руки → **«Предмет НЕ в руках — искать»**;
   - чередуйте, пока не останется **1** адрес.
6. **Авто-прокачка** или ручное изменение поля.
7. Вернитесь в игру, **переложите предмет**.

## Оружие — Type (33–47)

Каждый Type — **отдельная модель пушки** (не путать с уровнем 1–8).

| Type | Название |
|------|----------|
| **33** | Фотонная пушка |
| **34** | Промышленный лазер |
| **35** | Разрывное орудие |
| **36** | Гравитонный лучемёт |
| **37** | Ретрактор *(замедляет)* |
| **38** | Фазер Келлера |
| **39** | Красный бластер |
| **40** | Дефибриллятор |
| **41** | Субмезонная пушка |
| **42** | Аннигилятор поля |
| **43** | Тахионный резец |
| **44** | Прожектор вихря |
| **45** | Абсолютная матрица |
| **46** | **Адская волна** |
| **47** | Глаза Махпеллы |

> В памяти иногда рядом лежит отдельный **ID модели** (например `4424` у Адской волны, `3104` у промышленного лазера).  
> Авто-режим для оружия ставит **Type = 46** и **ID = 4424**.

Уровень **1–8** меняет ступень/иконку и базу для подписи «+XXX», но **не** подменяет модель 33–47.

## Типы предметов (CreateItemByType)

Классы, которые создаёт игра (по дизассемблу):

| Type (dec) | hex | Класс / смысл |
|------------|-----|----------------|
| 0–7 | 0x00–0x07 | Товары (`TGoods`) |
| 9–18 | 0x09–0x12 | Артефакты (`TArtefact`) |
| 26 | 0x1A | Топливный бак (`TFuelTank`) |
| 27 | 0x1B | Двигатель (`TEngine`) |
| 28 | 0x1C | Радар (`TRadar`) |
| 29 | 0x1D | Сканер (`TScaner`) |
| 31 | 0x1F | Захват / карго-крюк (`TCargoHook`) |
| 32 | 0x20 | Генератор защиты / щит (`TDefGen`) |
| **33–47** | **0x21–0x2F** | **Оружие (`TWeapon`)** — см. таблицу выше |
| 48 | 0x30 | Прототип / особое (`TProtop`) |

Точные «имя в трюме» для двигателей, баков, дроидов и т.д. зависят от **расы + уровня 1–8** (строки из `Rus.dat` / `Eng.dat`).

### Примеры имён оборудования (ступени 1–8)

**Дроиды (ремонт):** рельсовый → … → суспензорный (ур. 8).  
**Двигатели:** реакторный → … → сингулярный; у клисан — «жабродюзы» и т.п.  
**Топливные баки:** статичный → … → гипержидкостный; у клисан — «протопузырь».  
**Щиты:** точечный (5%) → … → октогенный (40% база); реальный % в памяти — **отдельный float**.

## Структура объекта в памяти (от адреса **цены**)

Якорь поиска — **цена** (4 байта, int). Остальное — фиксированные смещения:

### Общее почти для всех

| Смещение | Поле | Тип |
|----------|------|-----|
| `0` | **Цена** | int32 |
| `−8` | Вес | int32 |
| `−4` | Раса | int32 (0–5) |
| `+0x28` | Уровень | int32 или byte (1–8) |

### Оружие

| Смещение | Поле | Тип |
|----------|------|-----|
| `−0x18` | ID модели | int32 (напр. 4424) |
| `−0x14` | Type (33–47) | int32 |
| `+0x2C` | Дальность | int32 |
| `+0x30` | Мин. урон | byte |
| `+0x31` | Макс. урон | byte |

### Двигатель

| Смещение | Поле |
|----------|------|
| `+0x2C` | Скорость (int32) |
| `+0x30` | Варп (byte) |

### Топливный бак

| Смещение | Поле |
|----------|------|
| `+0x2C` | Объём (byte) |
| `+0x30` | Залито (byte) |

### Дрон

| Смещение | Поле |
|----------|------|
| `+0x28` | Уровень (byte) |
| `+0x29` | Регенерация (byte) |

### Захват

| Смещение | Поле |
|----------|------|
| `+0x2C` | Сила захвата (int32) |

### Защита (щит)

| Смещение | Поле |
|----------|------|
| `+0x2C` | **float** — множитель проходящего урона |

Формула щита в игре:

```text
урон_по_кораблю ≈ выстрел × float − броня
float = (100 − %защиты) / 100
```

| float | Защита на экране |
|-------|------------------|
| 0.95 | 5% |
| 0.60 | 40% |
| 0.10 | 90% |
| 0.01 | 99% |
| 0.00 | 100% |

### Радар

| Смещение | Поле |
|----------|------|
| `+0x2C` | Дальность радара (int32) |

### Сканер

| Смещение | Поле |
|----------|------|
| `+0x29` | Мощность сканирования (byte) |

## Как устроен поиск (логика CE)

1. Берёте предмет **в руку** → в памяти цена = ваше число.  
2. **Первый скан** по int32.  
3. Убираете с руки → цена в этом объекте **меняется**.  
4. Фильтр «изменилось» / снова «в руке с той же ценой».  
5. Повторяете, пока не останется один адрес — это **цена** предмета.  
6. Все правки — **относительно** этого адреса.

Редактируйте, находясь на **рабочем столе** (игра свёрнута / Alt+Tab), предмет при этом **в руке**.
